Além de saber como navegar pelo sistema e arquivos, é importante aprender a ler um arquivo. Um comando simples para usar é o comando cat, abreviação de concatenar, ele não apenas exibe o conteúdo do arquivo, mas pode combinar vários arquivos e mostrar a saída deles.

```bash
$ cat cores frutas
```

Não é ótimo para visualizar arquivos grandes e destina-se apenas a conteúdos curtos. Existem muitas outras ferramentas que usamos para visualizar arquivos de texto maiores que discutiremos na próxima lição.
